# Richer Surveynt workspace

## Scope

Shared firm/operator chrome now uses a cool slate canvas, layered white surfaces,
deep-blue navigation, selected contextual tabs, stronger headings and quieter
table headers. The website-form studio adds a blueprint preview canvas, device
controls, framed real renderer, refined controls and expandable readiness checks.
No primary destinations, pricing rules, permissions or provider gates changed.
Inspection paper, RICS questions, ratings and report content are excluded from
the new panel/button treatments. Existing reduced-motion and contrast settings
continue to take precedence.

IAB checks covered live heading propagation, light/dark appearance, mobile
preview selection and increased contrast/larger text/reduced-motion presentation.
The concept's native 1505px capture could not be fully captured in the desktop
side-panel browser (rightmost screenshot area blank under a wide override);
settled screenshots used the normal 1124px viewport, plus a 390px mobile check.
Screenshots are QA examples, not a pixel-identical clone of the concept.

No production migration or deployment. This is a shared visual polish pass,
not an assertion that every individual route received a separate visual audit.
