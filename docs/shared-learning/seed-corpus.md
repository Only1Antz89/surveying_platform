# Shared learning: seed corpus (plan)

Status: **not started. No seed content exists or has been commissioned.**

A seed corpus gives the first small firm useful shared assistance before any platform contributions exist. It must not contain RICS text or other third-party material without a licence. Surveynt's element taxonomy (A0) is the organising structure.

## Acquisition options

| Option | Notes | Rights and provenance needed |
|---|---|---|
| Commissioned cases written by qualified surveyors | Preferred. Each case is written as a generalised example, never a real property | Commissioning agreement assigning or licensing copyright to Surveynt; author attestation that no real client data is used |
| Staged photos of defects (built or mocked up) | For a future photo scope | Photographer agreement; model releases if any person appears; no location cues |
| Licensed educational material | Only with an explicit licence covering retrieval and display | Licence reference recorded per case |
| Synthetic generation | Bootstraps coverage only. **Not** a guarantee of privacy or accuracy | Provenance label; expert validation of every case |

## Ingestion path

Seed cases enter through the same technical review and release steps as contributions. They carry a dedicated pseudonymous contributor key (for example `seed`), so they are subject to the same contributor cap and coverage reporting. Each seed case records:

- its source (commissioned, licensed or synthetic);
- licence reference;
- author qualification;
- reviewer;
- review date;
- knowledge review date.

The release manifest reports seed and contributed shares separately.

## Coverage targets

To be set by qualified reviewers. The dimensions to cover are:

- service levels 1 to 3;
- England, Wales, Scotland and Northern Ireland, kept separate because guidance differs;
- main construction types and age bands;
- houses, flats and maisonettes;
- every building element in the taxonomy;
- ordinary and no-defect cases, as well as defects;
- less common conditions, labelled as such.

Segments without seed or contributed coverage are listed in each release manifest as unsupported, not filled by guesswork.

## Blockers

- Budget and a commissioning agreement.
- Qualified authors and reviewers.
- A licence check for any existing material.
