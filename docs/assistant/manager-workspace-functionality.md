# Manager workspace functionality

The manager Overview uses the tenant-scoped surveyor capacity loader. The Surveyors page has been restored to the previous ManagerStaff design at the user’s request; that component currently uses local preview surveyor records and local state. It counts assigned jobs excluding paid/archived work, reads declared active-job limits and authorised services from staff capabilities, resolves the active primary base, and counts today's confirmed appointments in Europe/London. Available headroom is a workload indicator; actual allocation still checks qualifications, coverage, calendars, working hours and buffers. Missing limits remain unknown rather than assuming a universal five-job limit. Profiles link to the existing staff profile. Local demo counts now agree with the demo job records; its capacity limits are unconfigured.

The manager page gates and remembered navigation now allow CRM, Finance and Reports & insights. Services, Locations and the administration routing configuration stay outside the manager workspace. Surveyors remain excluded from management analytics. Existing API role, tenant and billing restrictions remain authoritative.

CRM uses the existing client register and contact APIs, including creation, editing, contacts, search/type filters, CSV export and archiving. Links open the existing quote/instruction and website-enquiry workflows. Local preview clients persist in the scoped demo store. Detail and contact form dirty state are tracked separately and cleared after the relevant successful save.

Finance now uses the existing operational ledger, verified payment calculations and invoice workflows instead of the UI mock. Configured companies can create draft invoices, inspect lines/payments, issue or void eligible invoices, record supported receipts/credits/refunds, review external settlements and export ledger datasets according to their permissions. The local design preview has no live financial records and does not simulate financial writes or payment outcomes.

Reports & insights uses the actual date-filtered analytics API, a CSV download that retains the manager workspace, and links to report versions/review and the wording library. Current pipeline/workload indicators are independent of the selected period, as labelled. Preview indicators derive only from the demo jobs; dated quotes, payments, service creation events and issue durations are unavailable. CSV identifies the preview source and date boundaries.

Verification: 510 web tests passed. Web type checking and lint passed. Before restoring the previous Surveyors design, browser checks confirmed matching capacity counts; the same checks also confirmed persisted customer creation/reopening/editing, contact creation, manager Finance access, analytics date filtering and CSV download without browser errors. Temporary local customer test records were archived. Real database financial transactions and production tenant capacity queries have not been exercised because a configured test database is unavailable.
